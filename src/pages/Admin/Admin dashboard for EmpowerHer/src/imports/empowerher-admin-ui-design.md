Design a modern **Admin Dashboard UI** for a women empowerment startup called **EmpowerHer**.
This platform helps women entrepreneurs connect, learn skills, sell products, and access mentorship.

Create a **clean, professional, and responsive dashboard UI** with a soft feminine but professional color palette (purple, lavender, white, and subtle pink accents).

### Layout

Use a **left sidebar navigation + top navigation bar layout**.

### Sidebar Menu

Include the following menu items with icons:

* Dashboard
* Users / Members
* Mentors
* Courses / Skill Programs
* Marketplace Products
* Orders / Transactions
* Community Posts
* Reports & Analytics
* Messages / Support
* Settings
* Logout

### Dashboard Overview Page

Create cards and widgets showing:

* Total Users
* Active Women Entrepreneurs
* Total Courses
* Marketplace Sales
* New Registrations
* Pending Approvals

Add:

* Line chart showing **user growth**
* Bar chart for **monthly sales**
* Pie chart for **course enrollment categories**

### User Management Page

Design a table with:

* Profile photo
* Name
* Email
* Role (Entrepreneur / Mentor / Admin)
* Status (Active / Pending / Suspended)
* Actions (Edit / Delete / Approve)

Include **filters and search bar**.

### Course Management

Display course cards with:

* Course title
* Instructor
* Number of students
* Status (Active / Draft)
* Edit / Delete buttons
* Add new course button

### Marketplace Management

Product management table including:

* Product image
* Seller name
* Price
* Category
* Sales count
* Approval status

### Community Section

Moderate posts from users:

* Post preview
* Author
* Date
* Likes / Comments
* Approve / Remove actions

### Reports & Analytics

Create visual analytics widgets showing:

* User engagement
* Sales performance
* Top courses
* Top sellers

### UI Style

* Modern SaaS dashboard style
* Rounded cards
* Soft shadows
* Clean typography
* Consistent spacing
* Use component-based design
* Desktop-first layout with responsive structure

Generate **multiple frames/pages for each admin section** and reusable UI components.
